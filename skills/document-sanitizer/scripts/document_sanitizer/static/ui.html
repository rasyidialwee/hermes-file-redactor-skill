Document Sanitizer

Upload a file, pick a mode, preview what would reach the model.

  • secrets_only — API keys, JWT, PEM, passwords, auth headers, DB URLs
  • pii — secrets + email, phone, MyKad, IBAN, cards, BIN/BINTI names
  • confidential — pii + RM/MYR amounts, account-like numbers
  • strict — confidential + internal URLs, long numbers; hard image-byte block
  • off — no sanitization (pass-through; for comparison only)

Supported: txt, md, json, yaml, csv, xml, docx, xlsx, pdf, png/jpg/webp (OCR). Archives fail closed.
